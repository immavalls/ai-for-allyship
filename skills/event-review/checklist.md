# Event review checklist (CHAOSS-inspired, not official)

This is a practical screening aid, **not** the full CHAOSS application or review rubric. Check the [CHAOSS DEI Event Badging v4.0](https://www.chaoss.community/diversity-and-inclusion-badging/) source for current official criteria. Use the status rules in `SKILL.md` for each item.

| Theme | Look for publicly visible evidence | Follow-up if not found |
|---|---|---|
| Code of Conduct | Applicable policy linked directly, expected behavior, reporting channel, possible support/response details | Where is the policy? How are concerns reported and addressed? |
| Accessible participation | Venue or online platform access, captioning/interpretation where applicable, accommodations and request contact | How can people ask for access needs? |
| Tickets and financial access | Clear price/registration; scholarship or diversity-access tickets and eligibility if offered | Is support available, and how can someone apply? |
| Attendee and speaker feedback | Feedback channels and evidence of learning from prior events | How is inclusion feedback solicited and acted upon? |
| Demographic data practices | If collected, voluntary processes with opt-out and privacy protection | Are attendees free to decline disclosure? |
| Family friendliness | Published childcare/family support or alternatives where relevant | Are there accommodations or nearby resources? |
| Event location and timing | Public communications about relevant safety, accessibility, or timing constraints | Have organizers considered location-specific barriers? |
| Public health and safety | Published procedures/support appropriate to the setting | Where can attendees find current procedures? |
| Inclusive communication | Welcoming description, clearly stated prerequisites, multilingual information where available | Could wording discourage newcomers without justification? |
| Representation in visual assets | Diverse technical roles without obvious stereotypes; note limits of visual inference | Have organizers reviewed images for biased defaults? |

**Reporting caution:** Do not infer real attendance diversity or effectiveness of safeguards from a website. Never score people's identity or attribute intent to organizers. Only report what the inspected sources establish.
