# Contributing

This is an early community project, not a finished inclusivity standard. Thoughtful improvements are welcome.

Useful contributions include real (appropriately anonymized) test cases; clearer English and Spanish guidance; language-specific nuance; accessibility and event-safety resources; false-positive examples; inclusive imagery examples; and constructive event-review criteria.

1. Open an issue describing the problem, expected behavior, and any relevant context.
2. Propose a change in a pull request with one or two examples of how the change affects an AI output.
3. Avoid publishing private demographic, health, or harassment reports; seek consent for personal stories and images.
4. Cite original references, distinguish evidence from opinion, and respect authors' licenses.
5. Keep the tone constructive. Inclusion is context-sensitive and disagreements should be handled respectfully.

Changes to the event-review checklist must preserve source citations, uncertainty labels, and a no-score/no-badge rule. Tests and community feedback will be developed as the project matures.
